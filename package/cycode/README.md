# Cycode

Cycode is an application security company that provides an application
security posture management (ASPM) platform.

## What they offer

- **Code and supply chain security:** SAST, SCA, secrets detection and CI/CD
  security.
- **ASPM:** consolidation and prioritization of application security findings.
- **IaC and container scanning:** detection of misconfigurations and
  vulnerabilities.
