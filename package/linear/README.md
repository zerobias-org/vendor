# Linear

Linear is a software company that builds a product development and
issue tracking tool for software teams.

## What they offer

- **Issue tracking:** issues, projects and cycles for planning and
  tracking engineering work.
- **Product planning:** roadmaps and initiatives across teams.
- **Integrations and API:** connections to GitHub, Slack and other
  tools, plus a GraphQL API.
