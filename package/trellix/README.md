# Trellix

Trellix is a cybersecurity company formed in 2022 by bringing together
McAfee Enterprise and FireEye. It provides extended detection and response
(XDR) and security products for endpoints, networks, email and data.

## What they offer

- **XDR and security operations:** detection, investigation and response
  across the Trellix portfolio and third-party tools.
- **Endpoint security:** endpoint protection and endpoint detection and
  response.
- **Network and email security:** network detection and response and email
  threat protection.
- **Data security:** data loss prevention and encryption.
