# BambooHR

BambooHR is a human resources software company based in Utah. It provides
cloud HR software for small and medium-sized businesses.

## What they offer

- **HR management:** employee records, onboarding and offboarding.
- **Hiring:** applicant tracking.
- **Payroll, time and benefits:** payroll, time tracking and benefits
  administration.
