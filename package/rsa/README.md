# RSA Security

RSA Security LLC is a cybersecurity company focused on identity and access
management. It is known for its SecurID authentication products.

## What they offer

- **Authentication:** multi-factor and passwordless authentication, including
  SecurID.
- **Identity governance:** access reviews and identity lifecycle management.
- **Access management:** single sign-on and access policies.
