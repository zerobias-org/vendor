# Lansweeper

Lansweeper is an IT asset management company. Its platform discovers
and inventories hardware, software, users and cloud assets across an
organization's network.

## What they offer

- **IT asset discovery:** agentless and agent-based scanning of IT, OT
  and IoT devices.
- **Asset inventory:** a central record of hardware, software and users.
- **Reporting:** built-in reports for audits, software licensing and
  vulnerability context.
