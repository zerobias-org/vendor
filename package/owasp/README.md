# OWASP Foundation

The OWASP Foundation (Open Worldwide Application Security Project) is a
non-profit foundation that works to improve the security of software
through open-source projects, chapters and conferences.

## What they offer

- **OWASP Top 10:** a widely used awareness document on the most
  critical web application security risks.
- **ASVS:** the Application Security Verification Standard.
- **SAMM:** the Software Assurance Maturity Model.
- **Open-source tools:** projects such as Dependency-Check and
  CycloneDX.
