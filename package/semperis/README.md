# Semperis

Semperis is a cybersecurity company focused on identity threat detection,
response and recovery for Active Directory and Microsoft Entra ID.

## What they offer

- **Directory security:** monitoring and protection of hybrid Active
  Directory.
- **Forest recovery:** backup and recovery of Active Directory after attacks.
- **Identity threat detection and response:** detection of identity-based
  attacks.
