# Datadog

Datadog, Inc. is a monitoring and security company headquartered in New York
City. Its SaaS platform gives teams visibility into infrastructure,
applications and logs across cloud and on-premises environments.

## What they offer

- **Observability:** infrastructure monitoring, APM, log management, real user
  monitoring and synthetics.
- **Security:** Cloud SIEM, cloud security posture management and application
  security.
- **Integrations:** hundreds of integrations with cloud providers, services
  and tools.
