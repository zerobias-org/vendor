# Tableau

Tableau is a visual analytics platform for exploring and sharing data.
Tableau Software was acquired by Salesforce in 2019.

## What they offer

- **Tableau Desktop and Cloud:** data visualization and dashboards.
- **Tableau Server:** self-hosted analytics.
- **Tableau Public:** free platform for publishing visualizations.
