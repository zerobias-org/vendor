# CycloneDX

CycloneDX is an OWASP full-stack bill of materials (BOM) standard. It is also
published by Ecma International as ECMA-424.

## What they offer

- **SBOM:** software bills of materials describing components and
  dependencies.
- **Other BOM types:** SaaSBOM, HBOM, ML-BOM, CBOM and others.
- **VEX and attestations:** vulnerability exploitability exchange and
  standards attestations.
