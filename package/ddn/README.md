# DataDirect Networks (DDN)

DataDirect Networks (DDN) is a data storage company focused on high-
performance computing (HPC) and AI workloads.

## What they offer

- **AI and HPC storage:** parallel file system appliances (EXAScaler, based on
  Lustre) for large-scale training and simulation.
- **Data intelligence:** data platforms for managing and serving data to AI
  pipelines.
