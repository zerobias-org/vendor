# Qualys

Qualys, Inc. is a provider of cloud-based IT, security and compliance
solutions. Its platform automates asset discovery, vulnerability management
and compliance auditing.

## What they offer

- **Vulnerability management:** detection, prioritization and remediation of
  vulnerabilities.
- **Policy compliance:** configuration assessment against security benchmarks.
- **Cloud and web application security:** cloud posture and web application
  scanning.
- **Asset management:** continuous IT asset inventory.
