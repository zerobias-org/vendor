# Wasabi Technologies

Wasabi Technologies is a cloud storage company headquartered in Boston,
Massachusetts. It provides S3-compatible object storage.

## What they offer

- **Wasabi Hot Cloud Storage:** S3-compatible object storage with no fees for
  egress or API requests.
- **Backup and archive storage:** storage targets for backup and data
  protection software.
- **Surveillance and media storage:** storage for video surveillance and
  media workloads.
