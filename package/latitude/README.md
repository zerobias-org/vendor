# Latitude

Latitude is the company behind AI Dungeon, an AI-powered interactive
text adventure game in which players create stories with generative AI.

## What they offer

- **AI Dungeon:** an interactive storytelling game driven by AI models.
- **Community content:** user-created scenarios and adventures shared
  with other players.
