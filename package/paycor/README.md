# Paycor

Paycor is an HR and payroll software company based in Cincinnati, Ohio.
It was acquired by Paychex in 2025.

## What they offer

- **Payroll:** payroll processing and tax filing.
- **HR:** HR management, onboarding and compliance tools.
- **Talent management:** recruiting, learning and performance.
- **Workforce management:** time, attendance and scheduling.
