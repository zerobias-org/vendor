# Cloud Native Computing Foundation

The Cloud Native Computing Foundation (CNCF) is part of the Linux Foundation.
It hosts open-source projects for cloud native computing, including
Kubernetes.

## What they offer

- **Open-source projects:** hosts graduated, incubating and sandbox projects
  such as Kubernetes, Prometheus and Envoy.
- **Certification:** Kubernetes certifications (CKA, CKAD, CKS) and
  conformance programs.
- **Events:** KubeCon + CloudNativeCon.
