# Evernote

Evernote Corporation develops the Evernote note-taking and organization app.
The company was acquired by Bending Spoons in 2023.

## What they offer

- **Note-taking:** notes, web clips, documents and images synced across
  devices.
- **Organization:** notebooks, tags, search and task management.
- **Teams:** shared spaces for team knowledge.
