# mabl

mabl is a software test automation company. Its platform uses AI to
help teams create, run and maintain automated tests.

## What they offer

- **Test automation:** low-code and AI-assisted end-to-end tests for
  web and mobile apps.
- **API testing:** automated tests for APIs.
- **Performance and accessibility testing:** checks that run alongside
  functional tests.
