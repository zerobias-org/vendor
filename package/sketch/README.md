# Sketch

Sketch is a digital design platform for designing interfaces, prototypes and
design systems, with a native macOS app and web collaboration.

## What they offer

- **Design app:** a native Mac app for interface design.
- **Prototyping:** interactive prototypes from designs.
- **Collaboration and handoff:** sharing, commenting and developer handoff in
  the browser.
