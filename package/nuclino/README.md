# Nuclino

Nuclino is a team collaboration tool that brings knowledge, documents
and projects together in one shared workspace.

## What they offer

- **Team wiki:** a shared knowledge base with linked documents.
- **Docs:** real-time collaborative editing.
- **Project management:** boards and lists for tracking work.
