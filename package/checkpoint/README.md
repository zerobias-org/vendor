# Check Point Software Technologies

Check Point Software Technologies is a cybersecurity company headquartered in
Tel Aviv, Israel.

## What they offer

- **Network security:** Quantum firewalls and security gateways.
- **Cloud security:** CloudGuard for cloud networks and workloads.
- **Workspace security:** Harmony for endpoints, email and remote access.
