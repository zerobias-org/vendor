# OCSF

The Open Cybersecurity Schema Framework (OCSF) is an open-source project
that provides an extensible framework for cybersecurity event schemas.
It became a Linux Foundation project in November 2024.

## What they offer

- **Event schema:** a vendor-neutral schema of event classes, objects
  and attributes for security data.
- **Schema browser:** an online tool for exploring the schema.
- **Community:** contributions from security vendors and users.

## Official resources

- Schema browser: https://schema.ocsf.io/
