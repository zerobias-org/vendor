# JFrog

JFrog Ltd. is a software supply chain company best known for JFrog
Artifactory. Its platform stores, secures and distributes the binaries
and packages that teams build and release.

## What they offer

- **Artifact management:** JFrog Artifactory, a universal repository
  manager for packages, containers and build artifacts.
- **Software supply chain security:** JFrog Xray and JFrog Advanced
  Security for scanning dependencies and artifacts for vulnerabilities
  and license issues.
- **Distribution:** tools for releasing and distributing software
  across environments.
