# Exabeam

Exabeam is a cybersecurity company providing security information and event
management (SIEM) and security operations tools. It merged with LogRhythm in
2024.

## What they offer

- **SIEM and log management:** cloud-native and self-hosted security log
  collection, search and analytics.
- **UEBA:** user and entity behavior analytics for detecting insider threats
  and compromised accounts.
- **Threat detection, investigation and response:** AI-driven detection and
  automated investigation.
