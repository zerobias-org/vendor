# Barracuda Networks

Barracuda Networks, Inc. is a security company headquartered in Campbell,
California. It provides email, network, application and data protection
products.

## What they offer

- **Email protection:** email security, archiving and backup.
- **Network security:** firewalls and secure access.
- **Application and data protection:** web application firewalls and backup.
