# Gliffy

Gliffy is a diagramming tool, now part of Perforce Software. It is used to
create flowcharts, network diagrams, UML and other technical diagrams, mainly
inside Atlassian Confluence and Jira.

## What they offer

- **Diagrams for Confluence and Jira:** diagram creation and editing embedded
  in Atlassian products.
- **Online diagramming:** web-based editor with templates and shape libraries.
