# Cypress

Cypress.io, Inc. makes Cypress, an open-source JavaScript testing framework
for web applications.

## What they offer

- **Cypress App:** open-source end-to-end and component testing in the
  browser.
- **Cypress Cloud:** test recording, analytics, parallelization and flake
  detection.
