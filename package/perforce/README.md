# Perforce

Perforce Software is an enterprise software company that provides DevOps
solutions across the software development lifecycle. Its portfolio includes
Puppet, which it acquired in 2022.

## What they offer

- **Version control:** scalable version control for large code bases and
  binary assets.
- **Testing:** automated, mobile and web application testing tools.
- **Infrastructure automation:** configuration management and compliance
  automation through Puppet.
- **DevOps and planning:** tools for agile planning, application lifecycle
  management and collaboration.
