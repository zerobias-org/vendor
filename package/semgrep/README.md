# Semgrep

Semgrep is an application security company that makes a static analysis tool
of the same name for finding bugs and vulnerabilities in code.

## What they offer

- **Semgrep Code:** static application security testing (SAST).
- **Semgrep Supply Chain:** software composition analysis for dependencies.
- **Semgrep Secrets:** detection of hard-coded secrets.
