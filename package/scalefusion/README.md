# Scalefusion

Scalefusion is a unified endpoint management (UEM) platform for managing and
securing devices across operating systems.

## What they offer

- **Unified endpoint management:** management of Android, iOS, Windows, macOS
  and Linux devices.
- **Zero trust access:** identity and access controls for devices and users.
- **Endpoint security:** security policies and protection for managed devices.
