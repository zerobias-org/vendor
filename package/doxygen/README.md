# Doxygen

Doxygen is a free, open-source documentation generator. It produces reference
documentation from annotated source code, primarily C++ but also C, Java,
Python and other languages.

## What they offer

- **Documentation generation:** HTML, LaTeX/PDF, RTF and man page output from
  source comments.
- **Code visualization:** class hierarchy, call and collaboration graphs (with
  Graphviz).
