# Box

Box, Inc. is a cloud content management company headquartered in Redwood City,
California.

## What they offer

- **Content management:** secure file storage, sharing and collaboration.
- **Workflow and e-signature:** Box Relay and Box Sign.
- **Security and governance:** classification, retention and content
  protection.
- **AI:** Box AI for working with stored content.
