# Twilio

Twilio Inc. is a cloud communications company headquartered in San
Francisco, California. Developers use its APIs to add messaging, voice,
email and identity verification to applications.

## What they offer

- **Messaging:** APIs for SMS, MMS, WhatsApp and other messaging channels.
- **Voice and video:** programmable voice calling and related services.
- **Email (SendGrid):** email delivery API and marketing email.
- **Verify:** user verification and one-time passcodes.
- **Segment:** customer data platform for collecting and routing customer
  data.
