# Tanium

Tanium is an endpoint management and security company that provides
real-time visibility and control over endpoints.

## What they offer

- **Endpoint management:** asset inventory, patching and software
  deployment.
- **Endpoint security:** vulnerability, compliance and risk management.
- **Incident response:** investigation and remediation across endpoints.
