# Grafeas

Grafeas is an open-source artifact metadata API for auditing and governing the
software supply chain. It was started by Google and partners.

## What they offer

- **Metadata API:** a standard API and storage for metadata about software
  artifacts, such as builds, vulnerabilities and deployments.
- **Supply chain governance:** a basis for policy enforcement on what software
  is built and deployed.
