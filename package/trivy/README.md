# Trivy

Trivy is an open-source security scanner developed by Aqua Security. It finds
vulnerabilities, misconfigurations, secrets and license issues in container
images, file systems, code repositories, Kubernetes clusters and cloud
infrastructure.

## What they offer

- **Vulnerability scanning:** detection of known CVEs in OS packages and
  language dependencies.
- **Misconfiguration scanning:** checks of infrastructure as code such as
  Terraform, Kubernetes manifests and Dockerfiles.
- **Secret and license detection:** discovery of exposed secrets and
  software license information.
- **SBOM:** generation and scanning of software bills of materials.
