# Varonis

Varonis Systems is a data security company. Its platform discovers and classifies sensitive data, manages access to it
and detects threats against it across cloud and on-premises environments.

## What they offer

- **Data security posture management:** discovery and classification of
  sensitive data and its exposure.
- **Data access governance:** analysis of permissions and automated
  remediation of excessive access.
- **Threat detection and response:** behavior-based alerts on data access,
  backed by a managed data detection and response service.
- **Compliance:** reporting to support privacy and data protection
  regulations.
