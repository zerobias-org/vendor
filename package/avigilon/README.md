# Avigilon

Avigilon is a Motorola Solutions company based in Vancouver, Canada. It
designs and develops video security and access control products.

## What they offer

- **Video security:** surveillance cameras, video management software and
  video analytics.
- **Access control:** physical access control systems.
- **Cloud security suite:** cloud-managed video and access control.
