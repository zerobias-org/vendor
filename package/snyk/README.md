# Snyk

Snyk is a developer security company that helps teams find and fix
vulnerabilities in code, open-source dependencies, containers and
infrastructure as code.

## What they offer

- **Snyk Code:** static application security testing.
- **Snyk Open Source:** software composition analysis.
- **Snyk Container and IaC:** container image and infrastructure as code
  scanning.
