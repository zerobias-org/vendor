# NordLayer

NordLayer is a network security platform for businesses from Nord
Security, the company behind NordVPN.

## What they offer

- **Secure remote access:** business VPN and zero trust network access.
- **Network security:** threat protection and access controls for
  teams.
- **Management:** centralized administration of users, gateways and
  policies.
