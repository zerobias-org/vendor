# Imperva

Imperva is a cybersecurity company focused on application and data security.
It is part of Thales, which acquired it in 2023.

## What they offer

- **Application security:** web application firewall, DDoS protection, bot
  management and API security.
- **Data security:** data discovery, activity monitoring and protection for
  databases and data stores.
