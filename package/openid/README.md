# OpenID Foundation

The OpenID Foundation is a non-profit standards body that develops open
identity standards, including OpenID Connect.

## What they offer

- **OpenID Connect:** an identity layer on top of OAuth 2.0.
- **FAPI:** high-security API profiles used in open banking and similar
  ecosystems.
- **Shared Signals Framework:** standards for sharing security events
  between services.
- **Certification:** conformance testing for implementations.
