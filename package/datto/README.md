# Datto

Datto is a provider of IT solutions for managed service providers (MSPs) and
IT teams. It has been part of Kaseya since 2022.

## What they offer

- **Business continuity and disaster recovery:** backup appliances and cloud
  recovery for servers and endpoints.
- **SaaS protection:** backup for Microsoft 365 and Google Workspace data.
- **IT management:** remote monitoring and management (RMM), PSA and
  networking products.
