# Grokability

Grokability, Inc. is the company behind Snipe-IT, a free and open-source IT
asset management system written in PHP.

## What they offer

- **Snipe-IT:** tracking of hardware assets, software licenses, accessories,
  components and consumables.
- **Hosting and support:** hosted Snipe-IT plans and support for self-hosted
  installations.
- **API:** a REST API for integrations and automation.
