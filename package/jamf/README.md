# Jamf

Jamf is a software company that specializes in managing and securing Apple
devices in businesses and schools.

## What they offer

- **Device management:** Jamf Pro and Jamf School for macOS, iOS, iPadOS and
  tvOS.
- **Identity:** Jamf Connect for account provisioning and authentication on
  Mac.
- **Security:** Jamf Protect for endpoint security and threat detection on
  Apple devices.
