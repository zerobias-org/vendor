# Microsoft

Microsoft Corporation is a technology company headquartered in Redmond,
Washington. It builds operating systems, productivity software, cloud
infrastructure and security services.

## What they offer

- **Cloud platform:** Microsoft Azure.
- **Productivity and collaboration:** Microsoft 365.
- **Identity and security:** Microsoft Entra and Microsoft Defender.
- **Business applications:** Dynamics 365.
- **Operating systems:** Windows and Windows Server.
