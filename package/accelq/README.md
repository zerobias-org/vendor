# ACCELQ

ACCELQ is a software company that provides a cloud-based, codeless test
automation platform for web, mobile, API and enterprise applications.

## What they offer

- **Test automation:** codeless, AI-assisted test design and automation across
  web, mobile, API and desktop applications.
- **Enterprise application testing:** automated testing for packaged business
  applications such as Salesforce and other enterprise suites.
- **Test management:** planning, execution and reporting integrated with CI/CD
  pipelines.
