# Gruntwork

Gruntwork is an infrastructure-as-code company for Terraform and OpenTofu
users. It created and maintains Terragrunt, an open-source orchestration tool
for Terraform and OpenTofu.

## What they offer

- **Terragrunt:** open-source tool for managing infrastructure-as-code across
  many modules and environments.
- **Gruntwork Pipelines:** CI/CD for infrastructure changes.
- **IaC Library:** reusable, tested infrastructure modules.
