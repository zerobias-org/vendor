# Orca Security

Orca Security is a cloud security company that provides an agentless
cloud-native application protection platform (CNAPP) for multi-cloud
environments.

## What they offer

- **Cloud security posture management:** detection of misconfigurations
  and compliance gaps.
- **Workload protection:** vulnerability and threat detection in cloud
  workloads.
- **AI security:** visibility into AI models and services in the cloud.
- **Compliance:** reporting against common security frameworks.
