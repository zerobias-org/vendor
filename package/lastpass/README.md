# LastPass

LastPass is a password manager for individuals and businesses,
headquartered in Boston, Massachusetts. It stores passwords and other
sensitive data in an encrypted vault.

## What they offer

- **Password management:** personal, family and business password
  vaults with secure sharing.
- **Business administration:** policies, reporting and single sign-on
  for teams.
- **Shadow IT and SaaS visibility:** tools to discover the apps
  employees use.
