# VMware

VMware is a virtualization and cloud infrastructure software company. It has
been part of Broadcom since Broadcom completed its acquisition in 2023.

## What they offer

- **VMware Cloud Foundation:** a private cloud platform combining compute,
  storage and networking virtualization.
- **vSphere:** server virtualization.
- **vSAN and NSX:** software-defined storage and networking.
- **VMware Tanzu:** application platform for building and running
  applications.
