# Vermont

The State of Vermont is a US state. In this catalog it represents Vermont
laws and agencies that regulate consumer privacy and data security.

## What they offer

- **Data broker regulation:** registration and information security
  requirements for data brokers.
- **Security Breach Notice Act:** requirements for notifying consumers and
  the Attorney General of security breaches.
- **Attorney General:** enforces Vermont's consumer protection and privacy
  laws.
