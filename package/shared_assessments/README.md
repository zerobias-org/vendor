# Shared Assessments

The Shared Assessments Program is a member organization focused on
third-party risk management. It publishes tools and best practices for
assessing vendor risk.

## What they offer

- **Standardized Information Gathering (SIG) questionnaire:** a standard
  questionnaire for assessing vendor controls.
- **Standardized Control Assessment (SCA):** procedures for verifying vendor
  controls.
- **Certification and education:** third-party risk management training and
  credentials.
