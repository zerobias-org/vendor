# Palo Alto Networks

Palo Alto Networks, Inc. is a cybersecurity company headquartered in
Santa Clara, California. It is known for its next-generation firewalls
and security platforms.

## What they offer

- **Network security (Strata):** next-generation firewalls and SASE.
- **Cloud security (Prisma Cloud / Cortex Cloud):** cloud security and
  CNAPP.
- **Security operations (Cortex):** XDR, XSIAM and XSOAR.
- **Threat intelligence (Unit 42):** threat research and incident
  response.
