# FileWave

FileWave is a unified endpoint management (UEM) vendor. Its platform manages
and secures devices across macOS, Windows, iOS, Android and ChromeOS.

## What they offer

- **Endpoint management:** device enrollment, configuration, software
  deployment and patching.
- **IT asset management:** inventory and reporting across managed devices.
