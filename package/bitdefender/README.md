# Bitdefender

Bitdefender is a cybersecurity company founded in Romania. It provides
endpoint security and threat protection for consumers and businesses.

## What they offer

- **Business endpoint security:** the GravityZone platform for endpoint
  protection, detection and response.
- **Managed detection and response (MDR):** managed security services.
- **Consumer security:** antivirus and internet security products.
