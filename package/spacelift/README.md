# Spacelift

Spacelift is an infrastructure orchestration platform for infrastructure as
code tools such as Terraform, OpenTofu, Pulumi and Ansible.

## What they offer

- **IaC orchestration:** automated plan and apply workflows.
- **Policy as code:** guardrails for infrastructure changes.
- **Drift detection:** detection and remediation of infrastructure drift.
