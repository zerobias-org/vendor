# Read the Docs

Read the Docs is a documentation hosting platform that builds, versions and
hosts documentation for software projects. Its platform is open source.

## What they offer

- **Read the Docs Community:** free hosting for open-source documentation.
- **Read the Docs for Business:** private documentation hosting for
  companies.
- **Docs as code:** builds from Sphinx, MkDocs and other tools on every
  commit.
