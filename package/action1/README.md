# Action1

Action1 Corporation is a software company that provides a cloud-native
platform for patch management and remote endpoint management.

## What they offer

- **Patch management:** automated patching of operating systems and
  third-party applications.
- **Endpoint management:** remote monitoring, software deployment, scripting
  and remote access for managed endpoints.
- **Vulnerability remediation:** visibility into missing updates and
  vulnerabilities across the endpoint fleet.
