# Document360

Document360 is a knowledge base platform for creating and publishing product
documentation, help centers and internal knowledge bases.

## What they offer

- **Knowledge base:** authoring, versioning and publishing of public or
  private documentation.
- **AI features:** AI search, an AI chatbot and writing assistance.
- **Integrations:** API and integrations with support and collaboration tools.
