# OX Security

OX Security is an application security company that provides an
application security posture management (ASPM) platform covering code,
pipelines and cloud runtime.

## What they offer

- **ASPM:** visibility and prioritization of application security risk.
- **Software supply chain security:** protection of CI/CD pipelines and
  dependencies.
- **Code-to-runtime context:** linking risks to the exact code and
  runtime assets affected.
