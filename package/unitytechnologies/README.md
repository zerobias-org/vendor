# Unity Technologies

Unity Technologies is a software company headquartered in San Francisco,
California. It makes the Unity real-time 3D engine, which is widely used to
build games and interactive applications.

## What they offer

- **Unity engine:** a development platform for 2D, 3D, AR and VR content
  across mobile, desktop, console and web.
- **Unity Cloud and services:** multiplayer, DevOps, analytics and other
  services for live games.
- **Grow and monetization:** advertising and user acquisition solutions for
  app and game developers.
