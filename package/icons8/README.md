# Icons8

Icons8 is a design resources company that provides icons, illustrations,
photos and design tools for designers and developers.

## What they offer

- **Icons:** a large library of icons in consistent styles, available as SVG
  and PNG.
- **Illustrations and 3D:** illustration and 3D asset libraries.
- **Lunacy:** a free graphic design application.
