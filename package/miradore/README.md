# Miradore

Miradore is a mobile device management (MDM) product for managing and
securing Android, iOS, macOS and Windows devices. It is part of the
GoTo family of products.

## What they offer

- **Mobile device management:** enrollment, configuration and
  inventory of devices.
- **Security policies:** passcodes, encryption and remote lock or wipe.
- **Application management:** deployment of apps to managed devices.
