# Red Hat

Red Hat, Inc. is an open-source enterprise software company headquartered in
Raleigh, North Carolina. It has been a subsidiary of IBM since 2019.

## What they offer

- **Red Hat Enterprise Linux:** enterprise Linux operating system.
- **Red Hat OpenShift:** Kubernetes-based hybrid cloud application platform.
- **Red Hat Ansible Automation Platform:** IT automation.
- **Security advisories:** CVE data and errata for Red Hat products.
