# Godot Foundation

The Godot Foundation is a non-profit organization that supports the
development of the Godot Engine, a free and open-source game engine.

## What they offer

- **Godot Engine:** a free, MIT-licensed engine for 2D and 3D game
  development.
- **Funding and stewardship:** manages donations and funds work on the engine
  and its community.
