# HITRUST Alliance

HITRUST Alliance is an organization that develops and maintains the HITRUST
CSF, an information security and privacy framework widely used in healthcare
and other industries.

## What they offer

- **HITRUST CSF:** a certifiable framework that harmonizes requirements from
  standards and regulations such as ISO, NIST and HIPAA.
- **Assessments and certification:** e1, i1 and r2 assessments, performed by
  authorized external assessors.
- **Assessor programs:** credentials such as CCSFP for practitioners.
