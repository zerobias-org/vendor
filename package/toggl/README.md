# Toggl

Toggl is a software company that makes time tracking and work management
tools for individuals and teams.

## What they offer

- **Toggl Track:** time tracking with timers, reports, billable rates and
  project budgets across web, desktop and mobile apps.
- **Integrations and API:** browser extensions, integrations with other work
  tools and a public API for time data.
