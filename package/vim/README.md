# Vim

Vim is a free and open-source, highly configurable text editor. It was
created by Bram Moolenaar as an improved version of the vi editor and is
maintained by the Vim community.

## What they offer

- **Vim editor:** a modal text editor available on most operating systems,
  in terminal and graphical versions.
- **Scripting and plugins:** Vim script for customization and a large
  ecosystem of plugins.
- **Documentation:** built-in help and online documentation.

## Official resources

- Website: https://www.vim.org/
