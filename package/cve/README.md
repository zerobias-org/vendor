# CVE

The CVE (Common Vulnerabilities and Exposures) Program identifies, defines and
catalogs publicly disclosed cybersecurity vulnerabilities. It is operated by
MITRE with US government sponsorship (CISA).

## What they offer

- **CVE Records:** unique identifiers for publicly disclosed vulnerabilities.
- **CVE Numbering Authorities (CNAs):** a federated network of organizations
  that assign CVE IDs.
