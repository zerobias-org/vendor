# Falco

Falco is an open-source cloud native runtime security tool and a graduated
Cloud Native Computing Foundation (CNCF) project. It was originally created by
Sysdig.

## What they offer

- **Runtime threat detection:** monitors Linux kernel events and other sources
  against rules to detect suspicious behavior in hosts, containers and
  Kubernetes.
- **Rules and plugins:** a rules engine and plugins for sources such as
  Kubernetes audit logs and cloud logs.
