# National Information Assurance Partnership

The National Information Assurance Partnership (NIAP) is a US government
program, run by the National Security Agency (NSA), that oversees the
evaluation of commercial IT products for use in national security
systems. It runs the Common Criteria Evaluation and Validation Scheme
(CCEVS).

## What they offer

- **Protection Profiles:** approved Common Criteria security
  requirements for product types.
- **Product evaluations:** certification of products against Protection
  Profiles through accredited labs.
- **Product Compliant List:** a public list of certified products.
