# OffSec

OffSec (Offensive Security) is a cybersecurity training and
certification company focused on hands-on, offensive security skills.
It also maintains Kali Linux.

## What they offer

- **Certifications:** OSCP, OSEP, OSWE, OSED and other hands-on
  certifications.
- **Training:** courses and labs for penetration testing, defense and
  secure development.
- **Kali Linux:** an open-source Linux distribution for penetration
  testing.
