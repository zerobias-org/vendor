# SonarSource

SonarSource is a software company headquartered in Geneva, Switzerland. It
makes code quality and code security tools, including SonarQube.

## What they offer

- **SonarQube:** static analysis for code quality and security, self-managed
  or cloud.
- **SonarQube for IDE:** in-editor issue detection.
