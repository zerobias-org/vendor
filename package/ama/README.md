# American Medical Association

The American Medical Association (AMA) is the largest US association of
physicians, based in Chicago, Illinois. It develops, maintains and licenses
the CPT code set.

## What they offer

- **CPT code set:** Current Procedural Terminology codes for reporting medical
  procedures and services (HCPCS Level I).
- **Medical ethics and policy:** the AMA Code of Medical Ethics and health
  policy advocacy.
