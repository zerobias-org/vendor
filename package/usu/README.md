# USU

USU is a German software company that provides IT management and customer
service software for enterprises.

## What they offer

- **IT service management:** service desk and IT service management
  software.
- **IT asset and software asset management:** inventory, license management
  and optimization of software and SaaS spend.
- **Knowledge management:** knowledge base software for customer service
  agents and self-service.
- **IT monitoring and FinOps:** monitoring of IT systems and optimization of
  cloud costs.
