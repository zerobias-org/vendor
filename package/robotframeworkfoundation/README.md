# Robot Framework Foundation

The Robot Framework Foundation is a non-profit consortium of companies that
supports the development of Robot Framework, an open-source automation
framework for acceptance testing and robotic process automation.

## What they offer

- **Robot Framework:** a keyword-driven, open-source test automation framework.
- **Ecosystem support:** funding for development of the framework and its
  ecosystem.
- **Community:** events and community resources for Robot Framework users.
