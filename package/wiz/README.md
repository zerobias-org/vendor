# Wiz

Wiz is a cloud security company founded in 2020. Its agentless platform
scans cloud environments to find and prioritize security risks across
workloads, identities, data and code.

## What they offer

- **Cloud security posture management:** detection of misconfigurations and
  compliance issues across cloud accounts.
- **Workload and vulnerability scanning:** agentless scanning of virtual
  machines, containers and serverless functions.
- **Wiz Code and Wiz Defend:** code-to-cloud security and runtime threat
  detection and response.
- **Security graph:** correlation of risks to show attack paths.
