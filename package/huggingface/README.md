# Hugging Face

Hugging Face is an AI company and community platform for sharing machine
learning models, datasets and applications.

## What they offer

- **Hugging Face Hub:** hosting for models, datasets and Spaces (demo
  applications).
- **Open-source libraries:** Transformers, Datasets, Diffusers and other ML
  libraries.
- **Inference and deployment:** managed inference endpoints and enterprise
  features.
