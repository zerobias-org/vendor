# Aikido Security

Aikido Security is a software company based in Belgium that provides an
application security platform for developers.

## What they offer

- **Code security:** static analysis (SAST), open-source dependency scanning
  (SCA) and secrets detection.
- **Cloud and container security:** cloud posture management, container image
  and infrastructure-as-code scanning.
- **Runtime protection:** in-app protection against common attacks.
