# Kubescape

Kubescape is an open-source Kubernetes security platform. It was
created by ARMO and is a Cloud Native Computing Foundation (CNCF)
incubating project.

## What they offer

- **Posture management:** scans clusters and manifests for
  misconfigurations against frameworks such as NSA-CISA guidance and
  CIS Benchmarks.
- **Vulnerability scanning:** image and workload vulnerability scanning.
- **Runtime security:** detection of threats in running workloads.
