# AvePoint

AvePoint is a software company headquartered in Jersey City, New Jersey. It
provides data management, governance and protection solutions for Microsoft
365 and other cloud platforms.

## What they offer

- **Data security and governance:** information governance and access control
  for collaboration platforms.
- **Backup and resilience:** SaaS backup and recovery for Microsoft 365 and
  other cloud services.
- **Migration:** content and workload migration to Microsoft 365 and other
  platforms.
