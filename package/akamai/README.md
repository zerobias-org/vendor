# Akamai

Akamai Technologies, Inc. is a content delivery, cybersecurity and cloud
computing company headquartered in Cambridge, Massachusetts.

## What they offer

- **Content delivery:** global CDN for web, media and software delivery.
- **Security:** web application and API protection, DDoS mitigation, bot
  management and Zero Trust access.
- **Cloud computing:** cloud infrastructure services built on the former
  Linode platform.
