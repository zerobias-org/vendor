# OpenTofu

OpenTofu is an open-source infrastructure as code tool under the Linux
Foundation's stewardship. It is a community-driven fork of Terraform
and serves as a drop-in replacement for it.

## What they offer

- **Infrastructure as code:** declarative configuration for cloud and
  on-premises infrastructure.
- **Terraform compatibility:** works with existing Terraform
  configurations and providers.
- **Open governance:** community-driven development under an open-source
  license.
