# Dynatrace

Dynatrace is a software company that provides an AI-powered observability and
security platform for cloud and hybrid environments.

## What they offer

- **Observability:** infrastructure monitoring, application performance
  monitoring, logs and digital experience monitoring.
- **Application security:** runtime vulnerability analysis and protection.
- **AI and automation:** AI-driven root cause analysis and workflow
  automation.
