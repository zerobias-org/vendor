# Kape Technologies

Kape Technologies is a UK-based digital privacy and security company.
It owns several consumer VPN and privacy brands, including CyberGhost,
Private Internet Access and ExpressVPN.

## What they offer

- **Consumer VPN services:** CyberGhost VPN, Private Internet Access
  and ExpressVPN.
- **Privacy and security software:** consumer tools for protecting
  personal data and online activity.
