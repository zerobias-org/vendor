# Visily

Visily is an AI-powered UI design and wireframing tool. It helps teams
create wireframes, mockups and prototypes without needing design expertise.

## What they offer

- **Wireframing and mockups:** a design editor with templates and
  components.
- **AI design generation:** generation of designs from text prompts,
  screenshots and sketches.
- **Prototyping and collaboration:** clickable prototypes and real-time team
  collaboration.
