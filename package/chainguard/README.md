# Chainguard

Chainguard is a software supply chain security company. It provides minimal,
hardened container images and open-source packages built from source with low
or zero known vulnerabilities.

## What they offer

- **Chainguard Containers:** minimal, regularly rebuilt container images.
- **Chainguard Libraries:** language packages built from source.
- **Supply chain security:** SBOMs and signatures for its artifacts.
