# DataBee

DataBee, a Comcast company, is a security and compliance data platform from
Comcast Technology Solutions. It collects, normalizes and correlates security
data so teams can use it for analytics, risk and compliance reporting.

## What they offer

- **Security data fabric:** ingests and enriches data from security tools into
  a common, analytics-ready model.
- **Continuous controls monitoring:** dashboards that track security and
  compliance controls against the collected data.
