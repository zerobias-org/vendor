# Appdome

Appdome is a software company that provides a no-code platform for adding
security and anti-fraud protections to Android and iOS mobile apps.

## What they offer

- **Mobile app security:** app shielding, anti-tampering, obfuscation and
  encryption without SDKs or code changes.
- **Anti-fraud and anti-bot:** protections against fraud, malware, bots and
  account takeover in mobile apps.
- **Threat monitoring:** visibility into attacks against protected apps.
