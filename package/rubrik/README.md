# Rubrik

Rubrik, Inc. is a data security company that provides backup, recovery and
cyber resilience for enterprise, cloud and SaaS data.

## What they offer

- **Data protection:** backup and recovery across data center, cloud and SaaS.
- **Cyber recovery:** threat detection and recovery from ransomware.
- **Data security posture:** discovery and classification of sensitive data.
