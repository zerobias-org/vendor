# SmartBear

SmartBear Software makes tools for API development, software testing and
application quality. It maintains the Swagger tools for the OpenAPI
Specification.

## What they offer

- **Swagger:** API design and documentation tools for OpenAPI.
- **API testing:** tools such as SoapUI for functional API testing.
- **Test automation and management:** UI test automation and test management.
