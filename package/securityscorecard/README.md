# SecurityScorecard

SecurityScorecard is an information security company that rates the
cybersecurity posture of organizations using externally observed threat
signals.

## What they offer

- **Security ratings:** A–F scores for organizations' external security
  posture.
- **Third-party risk management:** monitoring of vendor and supply chain risk.
- **Threat intelligence:** research and data on external attack surfaces.
