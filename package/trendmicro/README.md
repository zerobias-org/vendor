# Trend Micro

Trend Micro is a cybersecurity company headquartered in Tokyo, Japan. It
provides security for enterprises, governments and consumers across
endpoints, cloud, networks and email.

## What they offer

- **Trend Vision One:** a security platform combining attack surface
  management, XDR and security operations.
- **Endpoint and server security:** protection for workstations, servers and
  workloads.
- **Cloud security:** protection for cloud workloads, containers and
  cloud accounts.
- **Network and email security:** intrusion prevention and email threat
  protection.
- **Threat research:** vulnerability research including the Zero Day
  Initiative bug bounty program.
