# Mile2

Mile2 is a cybersecurity training institute. It develops vendor-neutral
professional certifications, role-based training courses and hands-on
cyber range labs.

## What they offer

- **Certifications:** vendor-neutral cybersecurity certifications such
  as penetration testing, incident handling and information systems
  security.
- **Training courses:** role-based cybersecurity courses.
- **Cyber range labs:** hands-on lab environments for practice.
