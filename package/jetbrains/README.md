# JetBrains

JetBrains is a software company founded in 2000 that makes developer tools. It
is known for its IDEs and for creating the Kotlin programming language.

## What they offer

- **IDEs:** IntelliJ IDEA, PyCharm, WebStorm, GoLand, Rider and others.
- **Team tools:** TeamCity CI/CD and YouTrack issue tracking.
- **Code quality:** Qodana static analysis.
- **Kotlin:** a programming language for JVM, Android and multiplatform
  development.
