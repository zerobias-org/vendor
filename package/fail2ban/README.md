# Fail2Ban

Fail2Ban is a free, open-source intrusion prevention framework. It scans log
files for repeated malicious activity, such as failed logins, and bans the
offending IP addresses.

## What they offer

- **Log-based banning:** filters match patterns in service logs (SSH, web
  servers, mail and more).
- **Firewall actions:** updates firewall rules (iptables, nftables and others)
  to block offending hosts for a set time.
