# Qlik

Qlik is a data integration, data quality and analytics software company.

## What they offer

- **Analytics:** Qlik Sense for dashboards, self-service analytics and
  AI-assisted insights.
- **Data integration:** data movement, transformation and replication tools.
- **Data quality and governance:** tools for trusted, governed data.
