# FIDO Alliance

The FIDO Alliance is an open industry association whose mission is to reduce
the world's reliance on passwords. It develops authentication standards and
runs certification programs.

## What they offer

- **Passkeys:** phishing-resistant sign-in based on FIDO credentials.
- **Specifications:** FIDO2 (including CTAP, alongside the W3C WebAuthn
  standard), UAF and U2F.
- **Certification:** functional, security and biometric certification for
  authenticators and servers.
