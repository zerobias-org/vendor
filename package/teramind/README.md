# Teramind

Teramind is a software company that provides workforce analytics and insider
risk management. Its platform monitors user activity on endpoints to help
organizations detect insider threats, prevent data loss and understand
productivity.

## What they offer

- **Insider risk management:** user behavior analytics, policy-based alerts
  and automated responses to risky activity.
- **Data loss prevention:** detection and blocking of sensitive data
  exfiltration across applications, email, web and file transfers.
- **Workforce analytics:** activity, time and productivity insights for
  employees and remote teams.
