# WebdriverIO

WebdriverIO is an open-source test automation framework for Node.js. It
automates web browsers and mobile applications for end-to-end, component and
unit testing, and is a project of the OpenJS Foundation.

## What they offer

- **Browser automation:** testing based on the WebDriver and WebDriver BiDi
  protocols.
- **Mobile automation:** testing of native and hybrid mobile apps through
  Appium.
- **Test runner:** a configurable runner with support for test frameworks
  such as Mocha, Jasmine and Cucumber.
