# RapidAPI

RapidAPI provides an API hub where developers discover, connect to and manage
APIs, along with tools for publishing and testing APIs.

## What they offer

- **API Hub:** a marketplace for finding and subscribing to public APIs.
- **Enterprise API hub:** internal API catalogs for organizations.
- **API testing:** tools to design and test APIs.
