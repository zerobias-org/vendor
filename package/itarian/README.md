# ITarian

ITarian is an IT management platform for managed service providers and IT
teams, powered by the Xcitium platform.

## What they offer

- **Remote monitoring and management:** RMM, patch management and remote
  desktop.
- **Service desk:** ticketing and service management.
- **Device and endpoint security:** MDM and endpoint security capabilities.
