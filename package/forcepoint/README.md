# Forcepoint

Forcepoint is a cybersecurity company headquartered in Austin, Texas, focused
on data security.

## What they offer

- **Data security:** data loss prevention (DLP), data security posture
  management and data classification.
- **Security service edge:** secure web gateway, CASB and zero trust network
  access.
- **Network security:** next-generation firewall.
