# ExpressVPN

ExpressVPN is a virtual private network (VPN) provider offering apps for
consumer devices and routers.

## What they offer

- **VPN service:** encrypted connections through servers in many countries,
  using its Lightway protocol among others.
- **Privacy features:** password manager and other privacy tools bundled with
  subscriptions.
