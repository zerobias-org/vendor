# Superblocks

Superblocks is a platform for building internal enterprise applications,
including AI-generated apps, with centralized governance by IT.

## What they offer

- **App building:** generate and build internal apps on company data.
- **Governance:** central management of authentication, integrations, access
  controls and auditing.
