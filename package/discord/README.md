# Discord

Discord Inc. is a communications company headquartered in San Francisco,
California. Its platform provides voice, video and text chat organized into
communities called servers.

## What they offer

- **Communication platform:** servers, channels, direct messages, voice and
  video calls.
- **Developer platform:** APIs and SDKs for bots, apps and activities.
- **Safety:** moderation tools and safety policies for communities.
