# Sonrai Security

Sonrai Security is a cloud security company focused on cloud identity,
privileged access and permissions management.

## What they offer

- **Cloud permissions management:** discovery and removal of excess
  privileges.
- **Privileged access controls:** restriction of sensitive cloud permissions.
- **Identity security:** visibility into human and machine identities in the
  cloud.
