# Replit

Replit is a browser-based software creation platform where users build,
run and deploy apps, including with its AI agent.

## What they offer

- **Replit Agent:** AI that builds apps and websites from natural language.
- **Online IDE:** a cloud development environment for many languages.
- **Deployments:** hosting for apps built on Replit.
