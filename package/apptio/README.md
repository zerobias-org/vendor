# Apptio

Apptio is a software company that provides technology business management
(TBM) and IT financial management software. It is an IBM company.

## What they offer

- **IT financial management:** cost transparency and planning for IT spend.
- **Cloud financial management (FinOps):** cloud cost management and
  optimization (Cloudability).
- **Strategic portfolio management:** investment planning and agile portfolio
  management (Targetprocess).
