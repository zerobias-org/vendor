# Alaska

The State of Alaska is a US state. In this catalog it represents Alaska state
laws and agencies that apply to organizations handling the personal
information of Alaska residents.

## What they offer

- **Personal Information Protection Act:** Alaska's law on security
  breaches, credit report security freezes and protection of personal
  information (Alaska Statutes Title 45, Chapter 48).
- **Department of Law:** the Attorney General's office, which handles
  consumer protection matters.
