# NordVPN

NordVPN is a consumer VPN service from Nord Security. It encrypts
internet traffic and routes it through VPN servers in many countries.

## What they offer

- **VPN service:** encrypted connections for desktop, mobile and other
  devices.
- **Threat protection:** blocking of malicious sites, trackers and ads.
- **Additional privacy features:** dedicated IP and multi-hop servers.
