# Fortinet

Fortinet, Inc. is a cybersecurity company headquartered in Sunnyvale,
California. It develops network security appliances, software and services.

## What they offer

- **Network security:** FortiGate next-generation firewalls running FortiOS.
- **Security Fabric:** integrated products for SASE, endpoint, email, OT and
  security operations.
- **Threat intelligence:** FortiGuard Labs research and security services.
