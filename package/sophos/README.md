# Sophos

Sophos is a cybersecurity company headquartered in the United Kingdom. It
provides endpoint, network and cloud security products and managed security
services.

## What they offer

- **Endpoint security:** endpoint protection and extended detection and
  response (XDR).
- **Managed detection and response:** 24/7 managed security operations.
- **Network security:** firewalls and secure access.
- **Central management:** Sophos Central cloud management platform.
