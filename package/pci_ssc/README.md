# PCI Security Standards Council

The PCI Security Standards Council (PCI SSC) is a global forum founded
by American Express, Discover, JCB International, Mastercard and Visa.
It develops and maintains security standards for payment account data.

## What they offer

- **PCI DSS:** the Payment Card Industry Data Security Standard.
- **Other standards:** PCI PIN Security, P2PE, Secure Software and
  Secure SLC, among others.
- **Assessor and product programs:** qualification of assessors (QSAs)
  and listing of validated products and solutions.
