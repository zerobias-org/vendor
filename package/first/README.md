# FIRST

FIRST, the Forum of Incident Response and Security Teams, is a global
association of incident response and security teams. It promotes cooperation
and maintains widely used security standards.

## What they offer

- **CVSS:** the Common Vulnerability Scoring System.
- **EPSS:** the Exploit Prediction Scoring System.
- **TLP:** the Traffic Light Protocol for sharing sensitive information.
- **Community:** membership, CSIRT and PSIRT services frameworks, and the
  annual FIRST conference.
