# Sumo Logic

Sumo Logic, Inc. provides a cloud-native log analytics platform for security
and observability.

## What they offer

- **Log analytics:** collection, search and analysis of log data.
- **Cloud SIEM:** security information and event management.
- **Observability:** monitoring and troubleshooting of applications and
  infrastructure.
