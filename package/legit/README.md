# Legit Security

Legit Security is an application security company that provides an
application security posture management (ASPM) platform.

## What they offer

- **ASPM:** visibility into application security risk across the
  software development lifecycle.
- **Secrets scanning:** detection of exposed secrets in code and
  development tools.
- **AI code security:** detection and remediation of risk in
  AI-generated code.
