# Bright Security

Bright Security is an application security company that provides dynamic
application security testing (DAST) for web applications and APIs.

## What they offer

- **DAST:** automated scanning of web applications and APIs for
  vulnerabilities.
- **Developer integration:** security testing in CI/CD pipelines.
