# Kubesec

Kubesec is an open-source tool for security risk analysis of
Kubernetes resources, maintained by ControlPlane. It scores Kubernetes
manifests against security best practices.

## What they offer

- **Manifest scanning:** scores Kubernetes YAML for security issues.
- **Several ways to run:** CLI binary, Docker image, local HTTP server
  and a hosted scanning API.
- **Integrations:** a Kubernetes admission controller and a kubectl
  plugin.
