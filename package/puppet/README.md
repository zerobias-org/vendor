# Puppet

Puppet is an infrastructure automation and configuration management platform.
Puppet, Inc. was acquired by Perforce Software in 2022, and Puppet is now part
of Perforce.

## What they offer

- **Configuration management:** declarative, model-based automation of server
  and infrastructure state.
- **Compliance automation:** continuous enforcement and reporting against
  security baselines.
- **Open source Puppet:** the community edition of the automation engine.
