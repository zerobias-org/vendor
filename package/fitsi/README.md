# FITSI

The Federal IT Security Institute (FITSI) is a non-profit certification body
for U.S. federal information security professionals.

## What they offer

- **FITSP certifications:** Federal IT Security Professional credentials for
  Auditors (FITSP-A), Managers (FITSP-M), Designers (FITSP-D) and Operators
  (FITSP-O).
- **Federal focus:** certifications built around federal security standards
  such as FISMA and NIST guidance.
