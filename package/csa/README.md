# Cloud Security Alliance

The Cloud Security Alliance (CSA) is a nonprofit organization that defines
best practices for cloud computing security.

## What they offer

- **Cloud Controls Matrix (CCM):** a cybersecurity control framework for cloud
  computing.
- **STAR program:** the Security, Trust, Assurance and Risk registry for cloud
  provider assurance.
- **Training:** certifications such as the Certificate of Cloud Security
  Knowledge (CCSK).
