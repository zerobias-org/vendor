# Safetica

Safetica is a Czech data security company that provides data loss prevention
and insider risk management software.

## What they offer

- **Data loss prevention:** discovery, classification and protection of
  sensitive data.
- **Insider risk management:** monitoring of risky user behavior.
- **AI data protection:** controls over sensitive data shared with AI tools.
