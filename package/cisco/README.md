# Cisco

Cisco Systems, Inc. is a networking and security technology company
headquartered in San Jose, California.

## What they offer

- **Networking:** routers, switches, wireless and data center networking.
- **Security:** firewalls, secure access, identity (Duo) and threat detection.
- **Observability and collaboration:** Splunk, ThousandEyes and Webex.
