# Eclipse Foundation

The Eclipse Foundation is a not-for-profit open-source software foundation
based in Brussels, Belgium. It provides governance and infrastructure for
hundreds of open-source projects.

## What they offer

- **Open-source projects:** the Eclipse IDE, Jakarta EE, Eclipse Temurin
  (Adoptium) and many others.
- **Working groups:** industry collaborations on open-source technologies and
  specifications.
- **Open VSX:** a vendor-neutral registry for VS Code extensions.
