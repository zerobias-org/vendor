# Addigy

Addigy is a software company that provides a cloud-based device management
platform for Apple devices, used by IT teams and managed service providers.

## What they offer

- **Apple device management (MDM):** enrollment, configuration and management
  of macOS, iOS, iPadOS and tvOS devices.
- **Patching and software deployment:** automated OS and application updates
  and software distribution.
- **Compliance and security:** device compliance benchmarks, policies and
  remote support tools.
