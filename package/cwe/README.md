# CWE

CWE (Common Weakness Enumeration) is a community-developed list of software
and hardware weakness types. It is maintained by MITRE.

## What they offer

- **Weakness catalog:** standard identifiers and descriptions for software and
  hardware weaknesses.
- **CWE Top 25:** the list of the most dangerous software weaknesses.

## Official resources

- Website: https://cwe.mitre.org/
- CWE list: https://cwe.mitre.org/data/index.html
- CWE Top 25: https://cwe.mitre.org/top25/
