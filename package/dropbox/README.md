# Dropbox

Dropbox, Inc. is a cloud storage and collaboration company headquartered in
San Francisco, California.

## What they offer

- **File storage and sync:** cloud storage, file sharing and sync across
  devices.
- **Documents and signatures:** Dropbox Sign for e-signatures and DocSend for
  secure document sharing.
- **Developer platform:** APIs and SDKs for integrating with Dropbox.
