# Playwright

Playwright is an open-source framework from Microsoft for end-to-end testing
and automation of web applications across Chromium, Firefox and WebKit.

## What they offer

- **Test runner:** Playwright Test for cross-browser end-to-end testing.
- **Browser automation library:** APIs for JavaScript/TypeScript, Python,
  .NET and Java.
- **Tooling:** code generation, trace viewer and debugging tools.
