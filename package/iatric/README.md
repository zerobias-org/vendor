# Iatric Systems

Iatric Systems, Inc. is a healthcare IT company and part of Harris Computer.
It provides EHR integration and interoperability solutions and services for
hospitals and health systems.

## What they offer

- **Integration and interoperability:** interfaces and integration between
  EHRs and other healthcare systems.
- **Healthcare IT services:** EHR-related services and solutions for
  healthcare organizations.
