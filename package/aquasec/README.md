# Aqua Security

Aqua Security is a cloud-native security company. It provides a platform for
securing containers, Kubernetes and cloud workloads, and maintains the
open-source scanner Trivy.

## What they offer

- **Cloud-native application protection (CNAPP):** security across the build,
  infrastructure and runtime of cloud-native applications.
- **Container and Kubernetes security:** image scanning, runtime protection
  and Kubernetes posture management.
- **Trivy:** open-source scanner for vulnerabilities, misconfigurations and
  secrets.
