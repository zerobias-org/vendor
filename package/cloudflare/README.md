# Cloudflare

Cloudflare, Inc. is a connectivity cloud company headquartered in San
Francisco, California. Its global network provides security, performance and
developer services.

## What they offer

- **Application security and performance:** CDN, DDoS protection, WAF and bot
  management.
- **Zero Trust and SASE:** secure access to applications and the internet.
- **Developer platform:** Workers, storage and AI services.
