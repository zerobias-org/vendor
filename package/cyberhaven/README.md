# Cyberhaven

Cyberhaven is a data security company that provides AI-powered data loss
prevention and data security posture management.

## What they offer

- **Data loss prevention (DLP):** data lineage-based detection and blocking of
  data exfiltration.
- **Data security posture management (DSPM):** discovery and classification of
  sensitive data.
- **AI usage security:** visibility and control of data shared with AI tools.
