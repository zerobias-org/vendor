# HashiCorp

HashiCorp is a software company that makes infrastructure automation and
security tools for cloud environments. It was acquired by IBM in 2025.

## What they offer

- **Terraform:** infrastructure as code for provisioning cloud and on-premises
  resources.
- **Vault:** secrets management, encryption and identity-based access.
- **Other products:** Consul, Nomad, Packer, Boundary and HCP (HashiCorp Cloud
  Platform).
