# Splunk

Splunk is a security and observability software company. It was acquired by
Cisco in 2024.

## What they offer

- **Splunk Enterprise and Splunk Cloud Platform:** search, analysis and
  visualization of machine data.
- **Security:** Splunk Enterprise Security (SIEM) and security orchestration.
- **Observability:** infrastructure and application monitoring.
