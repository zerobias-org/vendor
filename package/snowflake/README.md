# Snowflake

Snowflake Inc. is a cloud data platform company. Its platform provides data
warehousing, data lakes, data sharing and AI on top of major public clouds.

## What they offer

- **Data warehousing and lakes:** storage and SQL analytics at scale.
- **Data sharing:** secure sharing and a data marketplace.
- **AI and applications:** AI features and app development on Snowflake data.
