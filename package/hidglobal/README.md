# HID Global

HID Global is a provider of trusted identity solutions headquartered in
Austin, Texas. It is part of ASSA ABLOY.

## What they offer

- **Physical access control:** card readers, credentials and mobile access.
- **Identity and authentication:** smart cards, PKI and multi-factor
  authentication.
- **Secure issuance:** ID card printers and credential management.
