# Anchore

Anchore is a software supply chain security company. It provides an SBOM-based
platform for software composition analysis and container security, and
maintains the open-source tools Syft and Grype.

## What they offer

- **Anchore Enterprise:** SBOM management, vulnerability scanning and policy
  enforcement for containers and software.
- **Syft:** open-source tool for generating software bills of materials
  (SBOMs).
- **Grype:** open-source vulnerability scanner for container images and
  filesystems.
