# ManageEngine

ManageEngine is the enterprise IT management division of Zoho
Corporation. It makes software for IT operations, security and service
management.

## What they offer

- **IT service management:** ServiceDesk Plus help desk and ITSM.
- **Endpoint management:** Endpoint Central for device and patch
  management.
- **Identity and access management:** ADManager Plus, ADAudit Plus and
  related Active Directory tools.
- **Security and monitoring:** Log360 SIEM and OpManager network
  monitoring.
