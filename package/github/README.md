# GitHub

GitHub, Inc. is a software development platform headquartered in
San Francisco, California, and a subsidiary of Microsoft since 2018.
It hosts Git repositories and the tools teams use to build and ship code.

## What they offer

- **Source code hosting and collaboration:** repositories, pull requests,
  code review and issues.
- **Automation:** GitHub Actions for CI/CD.
- **Security:** GitHub Advanced Security (code scanning, secret scanning,
  dependency review).
- **Deployment options:** GitHub Enterprise Cloud and GitHub Enterprise Server.
