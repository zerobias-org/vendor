# Render

Render is a cloud platform for building and running web applications,
services and databases, with automatic deploys from Git.

## What they offer

- **Application hosting:** web services, static sites, background workers and
  cron jobs.
- **Managed data stores:** managed PostgreSQL and key-value stores.
- **Networking:** managed TLS, a global CDN and private networking.
