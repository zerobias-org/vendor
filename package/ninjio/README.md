# NINJIO

NINJIO is a cybersecurity awareness training company. Its training uses
short, animated micro-learning videos based on real-world attacks.

## What they offer

- **Security awareness training:** short episodic training videos.
- **Phishing simulation:** simulated phishing tests.
- **Human risk management:** personalized coaching based on user
  behavior.
