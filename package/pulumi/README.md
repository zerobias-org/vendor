# Pulumi

Pulumi is an infrastructure as code company. Its open-source engine lets
teams define cloud infrastructure in general-purpose programming languages
such as TypeScript, Python, Go and C#.

## What they offer

- **Pulumi IaC:** open-source infrastructure as code for many cloud providers.
- **Pulumi Cloud:** managed state, deployments and team collaboration.
- **Secrets and policy:** secrets management and policy as code.
