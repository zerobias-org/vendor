# OpenText

OpenText Corporation is an information management software company
headquartered in Waterloo, Ontario, Canada. It acquired Micro Focus in
2023.

## What they offer

- **Content management:** enterprise content and document management.
- **Cybersecurity:** application security, identity and threat
  detection products.
- **IT operations and DevOps:** IT service management and application
  delivery tools.
- **Business network:** B2B integration and supply chain data exchange.
