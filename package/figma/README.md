# Figma

Figma, Inc. is a collaborative design software company headquartered in San
Francisco, California.

## What they offer

- **Figma Design:** browser-based interface design and prototyping.
- **FigJam:** online whiteboard for collaboration.
- **Dev Mode:** design-to-code handoff for developers.
- **Developer platform:** REST API and plugin APIs.
