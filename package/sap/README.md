# SAP

SAP SE is an enterprise software company headquartered in Walldorf, Germany.
It is best known for enterprise resource planning (ERP) software.

## What they offer

- **ERP:** SAP S/4HANA and cloud ERP.
- **Business applications:** finance, supply chain, procurement, HR and
  customer experience software.
- **SAP Business Technology Platform:** data, analytics, integration and
  application development.
