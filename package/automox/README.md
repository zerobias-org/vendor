# Automox

Automox is a software company that provides a cloud-native platform for
endpoint management and patching across Windows, macOS and Linux.

## What they offer

- **Patch management:** automated OS and third-party application patching.
- **Endpoint configuration:** policies and scripting (Worklets) for
  configuring and remediating endpoints.
- **Inventory and reporting:** device and software inventory with compliance
  reporting.
