# Broadcom

Broadcom Inc. is a semiconductor and infrastructure software company
headquartered in Palo Alto, California. Its software business includes VMware,
CA Technologies and Symantec enterprise security.

## What they offer

- **Semiconductors:** networking, broadband, storage and wireless chips.
- **VMware Cloud Foundation:** private cloud and virtualization software.
- **Infrastructure software:** mainframe, enterprise software and Symantec
  security products.
