# CIS

The Center for Internet Security (CIS) is a US nonprofit organization that
develops security best practices and provides cybersecurity resources.

## What they offer

- **CIS Controls:** a prioritized set of cyber defense safeguards.
- **CIS Benchmarks:** consensus-based secure configuration guidelines for
  systems and software.
- **MS-ISAC:** the Multi-State Information Sharing and Analysis Center for US
  state, local, tribal and territorial governments.
