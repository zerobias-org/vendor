# Aiven

Aiven is a cloud data platform company founded in Finland. It provides fully
managed open-source data infrastructure on major public clouds.

## What they offer

- **Managed databases:** managed PostgreSQL, MySQL, Valkey and other
  open-source databases.
- **Streaming:** managed Apache Kafka and related streaming services.
- **Search and analytics:** managed OpenSearch, ClickHouse and Grafana.
