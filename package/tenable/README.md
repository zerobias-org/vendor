# Tenable

Tenable, Inc. is an exposure management company. It is known for the Nessus
vulnerability scanner.

## What they offer

- **Tenable One:** exposure management across IT, cloud, identity and OT.
- **Vulnerability management:** Nessus and Tenable Vulnerability Management.
- **Cloud and OT security:** cloud security posture and operational
  technology security.
