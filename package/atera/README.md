# Atera

Atera is a software company that provides a cloud-based IT management platform
for IT departments and managed service providers.

## What they offer

- **Remote monitoring and management (RMM):** monitoring, patch management and
  remote access for endpoints.
- **PSA and helpdesk:** ticketing, billing and service management.
- **AI for IT:** AI-assisted ticket handling and automation.
