# Black Duck

Black Duck Software, Inc. is an application security company. It was formerly
the Synopsys Software Integrity Group and became an independent company in
2024.

## What they offer

- **Software composition analysis (SCA):** open-source and third-party
  component and license risk management.
- **Static analysis (SAST):** Coverity static code analysis.
- **Dynamic testing (DAST):** web application and API security testing.
