# Vectra AI

Vectra AI is a cybersecurity company headquartered in San Jose, California.
It uses AI to detect and prioritize attacker behavior across networks,
identities and cloud environments.

## What they offer

- **Network detection and response (NDR):** detection of attacker behavior
  in network traffic.
- **Identity threat detection:** detection of attacks on Active Directory and
  Microsoft Entra ID identities.
- **Cloud and SaaS detection:** threat detection for public cloud and
  Microsoft 365.
- **Managed services:** managed detection and response delivered by Vectra.
