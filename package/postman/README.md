# Postman

Postman, Inc. makes an API platform used to design, build, test, document and
collaborate on APIs.

## What they offer

- **API client and testing:** send requests, write tests and run collections.
- **API design and documentation:** define, mock and publish API
  specifications and docs.
- **Collaboration:** shared workspaces and a public API network.
