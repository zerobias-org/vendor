# Penpot

Penpot is an open-source design and prototyping platform for teams building
digital products. It runs in the browser and can be used as a hosted service
or self-hosted.

## What they offer

- **Design and prototyping:** collaborative interface design, components and
  interactive prototypes.
- **Design-to-code handoff:** open standards (SVG, CSS) that developers can
  inspect and reuse.
- **Self-hosting:** the open-source code base can be deployed on your own
  infrastructure.
