# Hexnode

Hexnode is a unified endpoint management (UEM) vendor and a product of Mitsogo
Inc.

## What they offer

- **Unified endpoint management:** management of mobile devices, desktops,
  rugged devices and IoT across major operating systems.
- **Security:** endpoint security and XDR capabilities.
- **Kiosk and app management:** kiosk mode, app deployment and content
  management.
