# Sysdig

Sysdig is a cloud security company focused on runtime security for
containers, Kubernetes and cloud environments. It created the open-source
Falco project.

## What they offer

- **Cloud-native application protection:** runtime threat detection,
  vulnerability management and posture management.
- **Cloud detection and response:** real-time detection of threats in
  cloud workloads.
- **Falco:** open-source runtime security, now a CNCF project.
