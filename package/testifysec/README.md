# TestifySec

TestifySec is a software supply chain security company. It helps developer
and security teams require signed evidence for how software is built and
demonstrate technical controls for compliance.

## What they offer

- **TestifySec platform:** repository gates, signed execution evidence and
  mapping of evidence to technical controls.
- **Witness:** open-source tool, maintained by TestifySec, for creating and
  verifying in-toto software supply chain attestations.
- **Archivista:** open-source storage and query service for attestations,
  also maintained by TestifySec.
