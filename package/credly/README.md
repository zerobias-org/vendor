# Credly

Credly is a digital credential platform owned by Pearson. Organizations use it
to issue, manage and verify digital badges for skills and certifications.

## What they offer

- **Digital badges:** issuing and managing verifiable digital credentials.
- **Credential verification:** public verification of earned badges.
- **Workforce analytics:** skills insights from credential data.
