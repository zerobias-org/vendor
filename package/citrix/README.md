# Citrix

Citrix is a provider of virtualization, application delivery and secure access
software. It is a business unit of Cloud Software Group.

## What they offer

- **Virtual apps and desktops:** delivery of Windows applications and desktops
  to any device.
- **Secure access:** secure remote access to applications.
- **Application delivery:** NetScaler application delivery controllers.
