# Domo

Domo, Inc. is a cloud data and business intelligence company headquartered in
American Fork, Utah.

## What they offer

- **Data integration:** connectors and pipelines for bringing data from many
  sources into one platform.
- **BI and analytics:** dashboards, reporting and data visualization.
- **Apps and AI:** low-code data apps and AI features built on the platform.
