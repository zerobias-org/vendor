# Wazuh

Wazuh is a free and open-source security platform that unifies XDR and SIEM
capabilities for endpoints and cloud workloads. The Wazuh company also
offers a managed cloud service.

## What they offer

- **Threat detection and response:** endpoint agents, log analysis and
  active response.
- **SIEM:** log collection, correlation, alerting and dashboards.
- **Compliance and configuration assessment:** checks against benchmarks
  and support for regulations such as PCI DSS, HIPAA and GDPR.
- **Wazuh Cloud:** a hosted, managed Wazuh service.
