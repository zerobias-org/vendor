# Zed

Zed is an open-source code editor built by Zed Industries. It is written in
Rust and designed for performance and real-time collaboration.

## What they offer

- **Zed editor:** a fast code editor for macOS, Linux and Windows.
- **AI features:** agentic editing and AI assistance with a choice of
  language models.
- **Collaboration:** shared projects, calls and multiplayer editing.
- **Extensions:** support for languages, themes and tools through
  extensions.
