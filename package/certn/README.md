# Certn

Certn is a background screening company that provides online background checks
for employers and landlords.

## What they offer

- **Background checks:** criminal record, identity, employment and education
  verification.
- **International screening:** background checks across many countries.
- **API integrations:** screening integrated into HR and applicant tracking
  systems.
