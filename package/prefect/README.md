# Prefect

Prefect is a workflow orchestration platform for building, scheduling and
monitoring data pipelines written in Python. Its core is open source.

## What they offer

- **Prefect (open source):** Python framework for defining and running
  workflows.
- **Prefect Cloud:** managed orchestration with observability, automation
  and access control.
