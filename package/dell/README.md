# Dell Technologies

Dell Technologies Inc. is a technology company headquartered in Round Rock,
Texas. It sells PCs, servers, storage and networking hardware along with
related software and services.

## What they offer

- **Client devices:** laptops, desktops and workstations (Latitude, XPS,
  Precision).
- **Infrastructure:** PowerEdge servers, PowerStore and PowerScale storage,
  and data protection products.
- **Services:** deployment, support and managed services.
