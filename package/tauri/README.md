# Tauri

Tauri is an open-source framework for building small, fast desktop and mobile
applications with a web frontend and a Rust backend.

## What they offer

- **Cross-platform apps:** builds for Windows, macOS, Linux, iOS and Android.
- **Security-focused design:** a permissions model for system access.
- **Plugins:** an ecosystem of plugins for native functionality.
