# Checkr

Checkr, Inc. is a background check company headquartered in San Francisco,
California. It provides technology-driven employment screening.

## What they offer

- **Background checks:** criminal, motor vehicle, employment and education
  checks.
- **Identity and drug screening:** identity verification and drug and health
  screening.
- **API platform:** screening integrated into hiring workflows via API.
