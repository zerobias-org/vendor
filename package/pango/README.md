# Pango

Pango is a digital security company known for the Hotspot Shield VPN.
It provides consumer security tools and offers them to businesses that
bundle them into their own products.

## What they offer

- **VPN:** Hotspot Shield and other VPN products.
- **Consumer security tools:** password manager, antivirus, robocall
  blocking and identity theft protection.
- **Partner solutions:** off-the-shelf, white-label and hybrid security
  offerings for financial services, insurance, telecom and travel
  companies.
