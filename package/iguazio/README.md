# Iguazio

Iguazio is an AI and MLOps platform company. It was acquired by McKinsey &
Company in 2023 and is part of QuantumBlack, AI by McKinsey.

## What they offer

- **AI platform:** operationalizing machine learning and generative AI
  applications at scale.
- **MLRun:** an open-source MLOps orchestration framework.
