# SLSA

SLSA (Supply-chain Levels for Software Artifacts) is a security framework and
specification for improving software supply chain integrity. It is a project
of the Open Source Security Foundation (OpenSSF).

## What they offer

- **SLSA specification:** levels describing increasing supply chain security
  guarantees.
- **Provenance:** a format for describing how software artifacts were built.
