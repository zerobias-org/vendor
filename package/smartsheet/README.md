# Smartsheet

Smartsheet Inc. provides a software-as-a-service platform for collaboration
and work management.

## What they offer

- **Work management:** spreadsheet-style sheets, projects and dashboards.
- **Automation:** automated workflows and approvals.
- **Integrations and API:** connectors and a public API.
