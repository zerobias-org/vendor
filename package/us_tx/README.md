# Texas

The State of Texas is a US state. In this catalog it represents Texas laws
and agencies that regulate privacy, data security and state government IT.

## What they offer

- **Texas Data Privacy and Security Act:** consumer data privacy law enforced
  by the Texas Attorney General.
- **TX-RAMP:** the Texas Risk and Authorization Management Program for cloud
  services used by state agencies, run by the Department of Information
  Resources.
- **Data breach notification:** state requirements for notifying
  individuals and the Attorney General of breaches.
