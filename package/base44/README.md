# Base44

Base44 is an AI-powered platform for building apps and websites from
natural-language prompts. It is owned by Wix.

## What they offer

- **AI app builder:** generate full-stack web apps from a text description.
- **Built-in backend:** hosting, database, authentication and integrations for
  generated apps.
