# OASIS Open

OASIS Open is a non-profit standards consortium. It offers projects,
including open-source projects, a path to standardization and de jure
approval for use in international policy and procurement.

## What they offer

- **Security standards:** SAML, STIX and TAXII for threat intelligence,
  and CSAF for security advisories.
- **Document and data standards:** OpenDocument Format (ODF) and other
  open standards.
- **Open projects:** a home for open-source projects that want a
  standards path.
