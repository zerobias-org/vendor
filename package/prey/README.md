# Prey

Prey makes device tracking, security and management software that helps
individuals and IT teams protect laptops, phones and tablets.

## What they offer

- **Device tracking:** locate devices and keep a location history.
- **Remote security actions:** lock, wipe and recover lost or stolen devices.
- **Fleet management:** inventory and management tools for IT teams.
