# Shortcut

Shortcut (formerly Clubhouse) is a project management platform for software
teams.

## What they offer

- **Issue tracking:** stories, epics and iterations for software work.
- **Planning:** roadmaps and objectives.
- **Docs and integrations:** team documentation and integrations with
  development tools.
