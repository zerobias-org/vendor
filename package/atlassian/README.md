# Atlassian

Atlassian is a software company that makes collaboration and development tools
for teams. It was founded in Sydney, Australia.

## What they offer

- **Jira:** issue, project and service management.
- **Confluence:** team wiki and knowledge management.
- **Developer tools:** Bitbucket for source code management and CI/CD.
