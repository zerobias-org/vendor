# Trello

Trello is a visual project and task management tool owned by Atlassian.
Teams organize work as boards, lists and cards and collaborate on the web,
desktop and mobile.

## What they offer

- **Boards and cards:** Kanban-style boards with lists, cards, checklists,
  due dates and attachments, plus calendar and timeline views.
- **Automation:** built-in rules, buttons and scheduled commands to automate
  repetitive work.
- **Power-Ups and integrations:** add-ons that connect Trello to other tools.
- **REST API:** a developer API for building integrations and Power-Ups.
