# IT Glue

IT Glue is IT documentation software for managed service providers and IT
teams. It is part of Kaseya.

## What they offer

- **IT documentation:** structured documentation of assets, configurations,
  procedures and client information.
- **Password management:** secure credential storage and sharing.
- **Integrations:** syncs with PSA, RMM and other IT tools.
