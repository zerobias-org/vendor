# DNSimple

DNSimple Corporation provides DNS hosting and domain management services for
developers and businesses, with an API-first approach.

## What they offer

- **Domains:** domain registration, transfers and renewals.
- **DNS hosting:** authoritative DNS with record management, secondary DNS and
  DNSSEC.
- **SSL certificates:** certificate ordering and renewal.
- **API and integrations:** a REST API and integrations for automating domain
  and DNS operations.
