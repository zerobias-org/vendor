# Certero

Certero is a software company that provides an IT asset management platform
(CerteroX).

## What they offer

- **IT asset and software asset management:** discovery, inventory and license
  compliance.
- **SaaS and cloud management:** visibility and cost management for SaaS and
  cloud.
- **Software licensing:** license management for major software publishers.
