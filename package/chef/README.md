# Chef Software

Chef is an infrastructure automation and DevOps software provider. It is part
of Progress Software, which acquired Chef Software in 2020.

## What they offer

- **Chef Infra:** configuration management as code.
- **Chef InSpec:** compliance and security testing as code.
- **Chef Habitat and Automate:** application automation and visibility across
  the fleet.
