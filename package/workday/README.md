# Workday

Workday, Inc. is an enterprise cloud software company headquartered in
Pleasanton, California. It provides applications for human resources,
finance and planning.

## What they offer

- **Human capital management:** HR, talent, recruiting, payroll and
  workforce management.
- **Financial management:** accounting, procurement, expenses and revenue
  management.
- **Planning:** enterprise planning and analytics (Workday Adaptive
  Planning).
- **AI and extensibility:** AI agents and a platform for extending Workday
  applications.
