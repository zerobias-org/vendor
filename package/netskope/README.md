# Netskope

Netskope is a cybersecurity company headquartered in Santa Clara,
California. It provides cloud-delivered security and networking
(SASE/SSE) for cloud, web, private applications and AI.

## What they offer

- **Security service edge (SSE):** secure web gateway, cloud access
  security broker (CASB) and zero trust network access (ZTNA).
- **Data protection:** data loss prevention across cloud, web and AI
  apps.
- **SD-WAN:** networking as part of a SASE architecture.
