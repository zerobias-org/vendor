# GitLab

GitLab Inc. is a software company that develops GitLab, a DevSecOps platform
for building, securing and deploying software. GitLab is open core and
available as SaaS or self-managed.

## What they offer

- **Source code management:** Git repositories, merge requests and code
  review.
- **CI/CD:** built-in pipelines for building, testing and deploying.
- **Security:** static and dynamic testing, dependency and container scanning,
  and compliance controls.
- **Planning:** issues, epics and boards.
