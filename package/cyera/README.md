# Cyera

Cyera is a data security company that provides an AI-native data security
platform.

## What they offer

- **Data security posture management (DSPM):** discovery and classification of
  sensitive data across cloud and SaaS.
- **Data loss prevention:** protection against data exfiltration.
- **AI security and identity:** controls for data access by people, identities
  and AI.
