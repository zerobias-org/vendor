# Docker

Docker, Inc. is a software company that develops tools for building, sharing
and running containerized applications. It created the Docker container
platform.

## What they offer

- **Docker Desktop:** local development environment for building and running
  containers.
- **Docker Hub:** registry for sharing and distributing container images.
- **Supply chain security:** Docker Scout for image analysis and vulnerability
  insights.
- **Open source:** Docker Engine and related open-source tooling.
