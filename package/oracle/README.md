# Oracle

Oracle Corporation is an enterprise software and cloud company. It is
known for the Oracle Database and Oracle Cloud Infrastructure.

## What they offer

- **Database:** Oracle Database and Autonomous Database.
- **Cloud infrastructure:** Oracle Cloud Infrastructure (OCI).
- **Business applications:** Oracle Fusion Cloud applications and
  NetSuite.
- **Java:** the Java platform and related tools.
