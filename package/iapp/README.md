# IAPP

The International Association of Privacy Professionals (IAPP) is a global
community and resource for privacy and data protection professionals.

## What they offer

- **Certifications:** CIPP (with regional concentrations), CIPM, CIPT and
  AIGP.
- **Resources:** privacy news, research, events and training.

## Official resources

- Website: https://iapp.org/
- Certification: https://iapp.org/certify/
