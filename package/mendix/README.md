# Mendix

Mendix is a low-code application development platform company. It has
been part of Siemens since 2018.

## What they offer

- **Low-code development:** visual modeling for building web and mobile
  applications.
- **Deployment options:** Mendix Cloud, private cloud and on-premises.
- **Enterprise integration:** connectors and data hub for enterprise
  systems.
