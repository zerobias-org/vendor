# HubSpot

HubSpot, Inc. is a customer relationship management (CRM) software company
headquartered in Cambridge, Massachusetts.

## What they offer

- **Smart CRM:** the shared customer database behind all HubSpot products.
- **Hubs:** Marketing, Sales, Service, Content, Operations and Commerce Hubs.
- **Developer platform:** APIs, apps and integrations.
