# BeyondTrust

BeyondTrust is a cybersecurity company headquartered in Atlanta, Georgia. It
provides identity security and privileged access management (PAM) products.

## What they offer

- **Privileged access management:** password and session management for
  privileged accounts.
- **Endpoint privilege management:** removal of local admin rights and
  application control.
- **Secure remote access:** remote support and privileged remote access.
- **Identity security insights:** detection of identity-based threats.
