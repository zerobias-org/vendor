# UI Bakery

UI Bakery is a low-code platform for building internal tools. Teams use it
to create admin panels, dashboards and business applications connected to
databases and APIs.

## What they offer

- **Low-code app builder:** drag-and-drop UI components with JavaScript for
  custom logic.
- **AI-assisted building:** generation of apps and components from prompts.
- **Data connectors:** connections to SQL databases, APIs and SaaS tools.
- **Workflows:** automations and approval flows for business processes.
- **Deployment options:** cloud and self-hosted deployment.
