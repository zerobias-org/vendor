# Kubernetes

Kubernetes is an open-source system for automating the deployment,
scaling and management of containerized applications. It is developed
by the Kubernetes Authors community and hosted by the Cloud Native
Computing Foundation (CNCF).

## What they offer

- **Container orchestration:** scheduling, scaling and self-healing for
  containerized workloads.
- **Declarative configuration:** API-driven management of workloads,
  networking and storage.
- **Security features:** RBAC, Pod Security Standards, network policies
  and secrets management.
