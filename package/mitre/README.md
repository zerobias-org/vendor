# MITRE

The MITRE Corporation is a US not-for-profit organization that operates
federally funded research and development centers. It is widely known
in cybersecurity for public knowledge bases and catalogs it maintains.

## What they offer

- **MITRE ATT&CK:** a knowledge base of adversary tactics and
  techniques based on real-world observations.
- **CVE Program:** MITRE operates the program that assigns identifiers
  to publicly disclosed vulnerabilities.
- **CWE:** a catalog of common software and hardware weakness types.

## Official resources

- MITRE ATT&CK: https://attack.mitre.org/
- CVE Program: https://www.cve.org/
- CWE: https://cwe.mitre.org/
