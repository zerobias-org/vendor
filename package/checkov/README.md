# Checkov

Checkov is an open-source static analysis tool for infrastructure as code. It
was created by Bridgecrew, which is now part of Palo Alto Networks.

## What they offer

- **IaC scanning:** finds misconfigurations in Terraform, CloudFormation,
  Kubernetes, Helm and other formats.
- **Policy as code:** built-in and custom policies for security and
  compliance.
- **Supply chain checks:** scanning of open-source dependencies and secrets.
