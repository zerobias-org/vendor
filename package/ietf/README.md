# IETF

The Internet Engineering Task Force (IETF) is an open standards organization
that develops and promotes internet standards, published as RFCs.

## What they offer

- **Internet standards:** protocols such as TCP/IP-related standards, HTTP,
  TLS and DNS extensions.
- **Working groups:** open participation through mailing lists and meetings.
- **RFC series:** the published specifications, maintained by the RFC Editor.

## Official resources

- Website: https://www.ietf.org/
- Datatracker: https://datatracker.ietf.org/
- RFC Editor: https://www.rfc-editor.org/
