# REST Assured

REST Assured is an open-source Java library that provides a domain-specific
language for testing and validating REST services.

## What they offer

- **REST API testing:** a fluent Java DSL for HTTP requests and response
  assertions.
- **Response validation:** JSON and XML path assertions and schema
  validation.
- **Framework integration:** works with JUnit, TestNG and Spring.
