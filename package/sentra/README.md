# Sentra

Sentra is a data security company that provides data security posture
management (DSPM) and AI data governance.

## What they offer

- **Data discovery and classification:** finds sensitive data across cloud and
  SaaS environments.
- **Data security posture management:** identifies data exposure and access
  risks.
- **AI data governance:** shows which data AI agents can reach and controls
  access.
