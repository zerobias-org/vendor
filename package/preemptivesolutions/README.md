# PreEmptive Solutions

PreEmptive is an application security company that protects software against
reverse engineering and tampering through code obfuscation and runtime
protection.

## What they offer

- **Dotfuscator:** protection for .NET and MAUI applications.
- **DashO:** protection for Java and Android applications.
- **JSDefender:** protection for JavaScript applications.
