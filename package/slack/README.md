# Slack

Slack is a messaging and collaboration platform for teams. Slack Technologies
was acquired by Salesforce in 2021.

## What they offer

- **Messaging:** channels, direct messages and huddles.
- **Workflow automation:** Workflow Builder and app integrations.
- **Enterprise controls:** security, compliance and data management features.
