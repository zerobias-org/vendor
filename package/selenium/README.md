# Selenium

Selenium is an open-source project that provides tools and libraries for
automating web browsers. Its WebDriver API is the basis of the W3C WebDriver
standard.

## What they offer

- **Selenium WebDriver:** language bindings for driving browsers.
- **Selenium Grid:** distributed execution of tests across machines and
  browsers.
- **Selenium IDE:** a browser extension for recording and replaying tests.
