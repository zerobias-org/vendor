# Motion Picture Association

The Motion Picture Association (MPA) is a trade association that
represents major film and television studios. It also runs the Trusted
Partner Network (TPN), a content security program for the entertainment
industry.

## What they offer

- **Trusted Partner Network (TPN):** an industry-wide content security
  initiative, wholly owned by the MPA, that assesses vendors and service
  providers.
- **Content security best practices:** security guidelines that TPN
  assessments are based on.
- **Advocacy:** policy and anti-piracy work for the film and television
  industry.
