# Databricks

Databricks, Inc. is a data and AI company headquartered in San Francisco,
California. It created the lakehouse architecture and is the original
developer of Apache Spark, Delta Lake and MLflow.

## What they offer

- **Data Intelligence Platform:** a lakehouse for data engineering,
  warehousing (Databricks SQL) and analytics.
- **Governance:** Unity Catalog for unified data and AI governance.
- **AI and machine learning:** tools to build, deploy and monitor ML models
  and generative AI applications.
