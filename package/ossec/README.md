# OSSEC

OSSEC is a free, open-source, multiplatform host-based intrusion
detection system (HIDS). Atomicorp manages and actively develops the
OSSEC project.

## What they offer

- **Host intrusion detection:** log analysis, file integrity monitoring
  and rootkit detection.
- **Active response:** automated responses to detected events.
- **Commercial support:** supported builds and services through
  Atomicorp.
