# South Carolina

The State of South Carolina is a US state. In this catalog it represents
South Carolina laws and agencies that regulate data security.

## What they offer

- **Insurance Data Security Act:** information security program and
  cybersecurity event notification requirements for insurance licensees,
  overseen by the Department of Insurance.
- **Data breach notification:** state requirements for notifying residents
  of breaches of personal identifying information.
