# GIAC

Global Information Assurance Certification (GIAC) is an information security
certification body affiliated with the SANS Institute.

## What they offer

- **Certifications:** hands-on credentials across cyber defense, incident
  response, penetration testing, forensics, cloud security and management,
  such as GSEC, GCIH, GPEN and GCFA.
- **Training alignment:** certifications that align with SANS training
  courses.
