# Apache Software Foundation

The Apache Software Foundation (ASF) is a US nonprofit that supports
community-led open-source software projects, released under the Apache
License.

## What they offer

- **Open-source projects:** stewardship of projects such as Apache HTTP
  Server, Kafka, Hadoop and Spark.
- **Apache License:** the Apache License 2.0, a widely used permissive
  open-source license.
- **Project governance:** the "Apache Way" of community governance and the
  Apache Incubator for new projects.
