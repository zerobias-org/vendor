# JumpCloud

JumpCloud Inc. is a cloud directory platform company. It gives IT teams
one place to manage user identities, access and devices across
operating systems.

## What they offer

- **Cloud directory:** user and group management as a cloud alternative
  to on-premises directories.
- **Access management:** single sign-on, multi-factor authentication
  and conditional access.
- **Device management:** MDM and patch management for Windows, macOS
  and Linux devices.
- **Privileged access:** controls for administrative access to systems.
