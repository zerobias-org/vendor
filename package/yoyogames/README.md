# YoYo Games

YoYo Games is the developer of GameMaker, a 2D game development engine. It
has been owned by Opera since 2021.

## What they offer

- **GameMaker:** a game engine and IDE for creating 2D games with visual
  scripting and the GML programming language.
- **Multi-platform export:** publishing to desktop, mobile, web and
  consoles.
- **GX.games:** a platform for publishing and playing browser games.
