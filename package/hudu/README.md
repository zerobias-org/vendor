# Hudu

Hudu is an IT documentation platform for managed service providers and
internal IT teams.

## What they offer

- **IT documentation:** structured documentation of clients, assets,
  configurations and procedures.
- **Password management:** secure storage and sharing of credentials.
- **Integrations:** integrations with PSA, RMM and other IT tools.
