# OctoXLabs

OctoXLabs is a cybersecurity company that provides a cyber asset
intelligence platform. It connects security, IT, cloud and identity
data sources into one continuously updated asset inventory.

## What they offer

- **Cyber asset attack surface management:** a unified view of assets
  from many data sources.
- **Risk prioritization:** identification of coverage gaps and risky
  assets.
- **Integrations:** connectors to security, IT, cloud and identity tools.
