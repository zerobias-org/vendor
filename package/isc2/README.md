# ISC2

ISC2 (formerly (ISC)²) is a nonprofit membership association for cybersecurity
professionals, best known for the CISSP certification.

## What they offer

- **Certifications:** CISSP, CCSP, SSCP, CGRC, CSSLP and the entry-level
  Certified in Cybersecurity (CC).
- **Continuing education:** training and professional development for members.
