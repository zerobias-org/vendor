# CircleCI

CircleCI is a continuous integration and continuous delivery (CI/CD) platform
for software teams, headquartered in San Francisco, California.

## What they offer

- **CI/CD pipelines:** cloud-hosted and self-hosted build, test and deploy
  pipelines.
- **Runners and execution environments:** Docker, Linux, macOS, Windows, Arm
  and GPU environments.
- **Insights:** pipeline analytics and test insights.
