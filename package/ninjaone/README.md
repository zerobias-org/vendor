# NinjaOne

NinjaOne is an IT management software company headquartered in Austin,
Texas. Its platform helps IT teams and managed service providers manage
and secure endpoints.

## What they offer

- **Remote monitoring and management:** endpoint monitoring, automation
  and remote access.
- **Patch management:** operating system and third-party patching.
- **Backup:** endpoint and server backup.
- **Mobile device management:** management of mobile devices.
