# Auvik

Auvik Networks is a software company based in Canada that provides cloud-based
network management and SaaS management software.

## What they offer

- **Network monitoring and management:** automated network discovery, mapping,
  monitoring and configuration backup.
- **SaaS management:** discovery and management of SaaS application usage.
- **Network traffic insights:** visibility into network traffic flows.
