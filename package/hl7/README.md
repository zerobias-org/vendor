# HL7 International

Health Level Seven International (HL7) is a not-for-profit, ANSI-accredited
standards developing organization for the exchange of electronic health
information.

## What they offer

- **FHIR:** Fast Healthcare Interoperability Resources, a standard for
  exchanging healthcare data through APIs.
- **HL7 Version 2:** messaging standard widely used between clinical systems.
- **CDA:** Clinical Document Architecture for clinical documents.
