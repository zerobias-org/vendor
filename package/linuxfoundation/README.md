# Linux Foundation

The Linux Foundation is a non-profit organization that hosts and
supports open-source projects, including Linux, Kubernetes (through the
CNCF) and SPDX.

## What they offer

- **Open-source project hosting:** governance, funding and services for
  hundreds of open-source projects.
- **SPDX:** an open standard (ISO/IEC 5962) for software bill of
  materials (SBOM) data.
- **Training and certification:** courses and certifications for
  open-source technologies.
