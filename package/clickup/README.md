# ClickUp

ClickUp is a productivity and project management platform headquartered in San
Diego, California.

## What they offer

- **Project and task management:** tasks, lists, boards, Gantt charts and
  goals.
- **Docs and collaboration:** documents, whiteboards and chat.
- **AI and automation:** AI features and workflow automations.
