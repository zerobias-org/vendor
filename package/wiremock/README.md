# WireMock

WireMock is an open-source tool for mocking HTTP APIs. Developers use it to
simulate APIs in tests and development. WireMock Inc. offers a commercial
hosted product, WireMock Cloud.

## What they offer

- **WireMock (open source):** a Java library and standalone server for
  stubbing and verifying HTTP requests.
- **WireMock Cloud:** a hosted API simulation platform for teams.
- **Request recording and fault simulation:** capturing real traffic and
  simulating delays and faults.
