# Sonatype

Sonatype is a software supply chain security company. It operates Maven
Central, the main public repository for Java components.

## What they offer

- **Nexus Repository:** artifact and component repository management.
- **Software composition analysis:** open-source risk and policy management.
- **Malware protection:** detection and blocking of malicious open-source
  components.
