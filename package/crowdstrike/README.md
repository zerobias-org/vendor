# CrowdStrike

CrowdStrike Holdings, Inc. is a cybersecurity company headquartered in Austin,
Texas. Its cloud-native Falcon platform protects endpoints, cloud workloads,
identities and data.

## What they offer

- **Endpoint security:** next-generation antivirus and endpoint detection and
  response (EDR/XDR).
- **Cloud security:** cloud workload and posture protection.
- **Identity protection:** detection of identity-based attacks.
- **Threat intelligence and services:** threat intelligence, managed threat
  hunting and incident response.
