# Nutanix

Nutanix, Inc. is a cloud infrastructure software company headquartered
in San Jose, California. It is known for hyperconverged infrastructure
and hybrid multicloud software.

## What they offer

- **Cloud infrastructure:** Nutanix Cloud Infrastructure, including the
  AHV hypervisor.
- **Unified storage:** file, object and block storage.
- **Management and automation:** Nutanix Cloud Manager.
- **Database and AI services:** database management and infrastructure
  for AI workloads.
