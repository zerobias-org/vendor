# Veeam

Veeam Software is a data protection and data resilience company. Its
products back up and recover data across virtual, physical, cloud and SaaS
environments.

## What they offer

- **Veeam Data Platform:** backup, recovery and ransomware protection for
  enterprise workloads.
- **Cloud and SaaS backup:** protection for public cloud workloads and SaaS
  applications such as Microsoft 365.
- **Kubernetes backup:** data protection for Kubernetes through Kasten.
- **Disaster recovery:** replication and orchestrated recovery.
