# OpenCRE

OpenCRE (Open Common Requirement Enumeration) is an open project that
links security requirements across standards and frameworks into one
common catalog. It is an OWASP project.

## What they offer

- **Requirement mapping:** links between equivalent requirements in
  standards such as OWASP ASVS, NIST guidance and ISO/IEC 27001.
- **Search and browse:** a web interface to explore requirements and
  their sources.
- **Open data:** an open catalog that tools can integrate.
