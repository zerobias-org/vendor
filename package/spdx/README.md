# SPDX

SPDX (System Package Data Exchange) is an open standard for communicating
software bill of materials (SBOM) information, including components,
licenses, copyrights and security references. It is a Linux Foundation
project and is published as ISO/IEC 5962:2021.

## What they offer

- **SPDX specification:** a standard format for SBOMs.
- **SPDX License List:** standardized identifiers for open-source licenses.

## Official resources

- Website: https://spdx.dev/
- Specification: https://spdx.github.io/spdx-spec/v3.0.1/
