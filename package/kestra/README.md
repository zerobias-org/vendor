# Kestra

Kestra is an open-source orchestration platform, developed by the
company of the same name. Workflows are defined in declarative YAML and
can run code in any language.

## What they offer

- **Workflow orchestration:** scheduling and event-driven workflows for
  data, infrastructure, IT operations and AI.
- **Open source:** the core platform is open source and can be self-hosted.
- **Enterprise and cloud editions:** commercial editions with features
  for larger teams.
