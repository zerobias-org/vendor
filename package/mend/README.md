# Mend.io

Mend.io, formerly known as WhiteSource, is an application security
company. Its platform finds and fixes risk in open-source dependencies,
custom code and AI components.

## What they offer

- **Software composition analysis (SCA):** open-source vulnerability and
  license risk detection.
- **Static application security testing (SAST):** scanning of
  first-party code.
- **Dependency updates:** Mend Renovate for automated dependency updates.
- **AI security:** security for AI models and AI-powered applications.
