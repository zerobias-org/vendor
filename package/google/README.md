# Google

Google LLC is a technology company headquartered in Mountain View, California,
and a subsidiary of Alphabet Inc. It provides search, advertising, cloud
computing, productivity software and consumer products.

## What they offer

- **Google Cloud:** cloud infrastructure, data analytics and AI services.
- **Google Workspace:** Gmail, Drive, Docs, Meet and other productivity tools.
- **Platforms:** Android, Chrome and ChromeOS.
- **Compliance:** certifications and attestations for Google Cloud and
  Workspace.
