# KICS

KICS (Keeping Infrastructure as Code Secure) is an open-source static
analysis tool for infrastructure as code. The project is powered by
Checkmarx.

## What they offer

- **IaC scanning:** finds security vulnerabilities, compliance issues
  and misconfigurations in IaC files.
- **Broad format support:** Terraform, Kubernetes, Docker,
  CloudFormation, Ansible and other formats.
- **Extensible queries:** rules are written as queries that users can
  customize or extend.
