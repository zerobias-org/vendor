# Virginia

The Commonwealth of Virginia is a US state. In this catalog it represents
Virginia laws and agencies that regulate consumer privacy and state
information security.

## What they offer

- **Virginia Consumer Data Protection Act:** consumer data privacy law
  enforced by the Virginia Attorney General.
- **Virginia IT Agency (VITA):** sets information security standards for
  state agencies.
- **Data breach notification:** state requirements for notifying residents
  of breaches of personal information.
