# Veracode

Veracode is an application security company. It provides testing to find and fix security flaws in
software throughout the development lifecycle.

## What they offer

- **Static analysis (SAST):** scanning of source and compiled code for
  security flaws.
- **Dynamic analysis (DAST):** testing of running web applications and APIs.
- **Software composition analysis (SCA):** detection of vulnerable and
  risky open-source dependencies.
- **Remediation:** guidance and AI-assisted fixes for detected flaws.
