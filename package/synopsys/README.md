# Synopsys

Synopsys, Inc. is a technology company that provides electronic design
automation (EDA) software, semiconductor IP and systems verification tools.

## What they offer

- **EDA tools:** software for designing and verifying chips.
- **Semiconductor IP:** licensable interface, processor and foundation IP.
- **Systems verification:** hardware-assisted verification and simulation.
