# Ivanti

Ivanti is an IT software company headquartered in South Jordan, Utah. It was
formed in 2017 from the combination of LANDESK and HEAT Software.

## What they offer

- **Endpoint management:** unified endpoint management and patch management.
- **Security:** zero trust access, including Ivanti Connect Secure VPN, and
  exposure management.
- **Service management:** IT service and asset management.
