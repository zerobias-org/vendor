# Notepad++

Notepad++ is a free, open-source source code editor and Notepad
replacement for Microsoft Windows. It is released under the GNU General
Public License.

## What they offer

- **Code editing:** syntax highlighting and folding for many
  programming languages.
- **Productivity features:** tabbed editing, search and replace with
  regular expressions, and macros.
- **Plugins:** an extensible plugin system.
