# Kolide

Kolide is a device trust product that checks whether devices are secure
before they can access applications. Kolide was acquired by 1Password,
and its device trust product is now part of 1Password Extended Access
Management.

## What they offer

- **Device trust:** blocks insecure devices from signing in to apps,
  with an integration for Okta.
- **Endpoint posture checks:** checks for macOS, Windows and Linux
  devices.
- **End-user remediation:** guides employees to fix issues on their
  own devices.
